# Skills del proyecto

- **diseno-linkyouth** (`.claude/skills/diseno-linkyouth/SKILL.md`) — sistema de
  diseño de la interfaz: paleta, tipografía, elevación, espaciado, patrones de
  componente, accesibilidad y tono de los textos. Usala **antes** de crear o
  modificar cualquier pantalla, componente o estilo.
- **datos-linkyouth** (`.claude/skills/datos-linkyouth/SKILL.md`) — modelo de
  datos sobre Supabase: esquema, Row Level Security, tipos, consultas y
  acciones de servidor. Usala antes de tocar cualquier cosa que lea o escriba
  datos.
- **graphify** (`.claude/skills/graphify/SKILL.md`) — cualquier entrada a grafo
  de conocimiento. Disparador: `/graphify`.

Cuando el usuario escriba `/graphify`, usá la skill de graphify antes que
cualquier otra cosa.
